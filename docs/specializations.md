# 유닛 전용 특화

공격·지원 병력 17종은 Lv.3부터 전용 특화 두 가지 중 하나를 선택한다.
비용은 해당 병력의 기본 배치 비용이며, 증강의 비용 배율을 적용한다.
선택한 특화는 Lv.4 이후 강화·주둔·하차·재배치·저장 복원에도 유지된다.
벙커는 레벨이 없는 수송 건물이므로 탑승한 병력이 각자의 특화를 선택한다.

| 병력 | 첫 번째 특화 | 두 번째 특화 |
| --- | --- | --- |
| 미사일 터렛 | 장거리 요격: 장거리 집중 사격 | 확산 탄두: 폭발형 일반 공격 |
| 시즈 탱크 | 공성 저격포: 장거리 단일 저격 | 광역 포격진: 폭발 반경 확대 |

| 드라군 | 위상 저격: 원거리 고위력 | 분열포 가속: 짧은 주기의 사격 |

| 스카우트 | 중무장 전투기: 장거리 화력 | 기동 타격대: 스킬 재사용 단축 |
| 캐리어 | 중형 인터셉터: 장거리 고위력 | 고속 출격: 짧은 출격 주기 |

수치와 정확한 적용 범위는 `src/specializations.ts`에서 관리하며,
작전실의 특화 아이콘 설명과 도감에 같은 정의를 사용한다.
공격력 배율은 일반 공격과 전용 스킬에 적용한다.
설명에 일반 공격·일반 폭풍으로 명시한 범위·둔화·영역 지속 효과는 전용 스킬을 바꾸지 않는다.
마린은 탑승 여부가 바뀌면 조건부 효과도 즉시 바뀐다.

## 기존 저장과 증강

- 저장의 `power` / `rapid` 키는 해당 병력의 첫째 / 둘째 특화로 읽는다. 저장 형식은 v1을 유지한다.
- 기존에 특화한 병력은 새 전용 효과가 적용된다.
- 이중 특화는 두 효과의 공격력·간격 배율을 곱하고, 추가 사거리·지원 효과를 더한다.
- 시즈 탱크의 이중 특화는 저격포의 공격력·사거리와 광역 포격진의 폭발 반경을 함께 얻는다.
- 전술 관제는 특화 보너스까지 포함해 가장 강한 두 베슬만 100% / 40%로 적용한다.
- 정밀 관측은 같은 옵저버의 표식을 중복 생성하지 않고 지속 시간만 갱신한다.
- 야마토 프로토콜과 아이어 증강의 일반 공격 변경은 각 증강의 공격 방식을 우선한다.

## 검증

`npm test`로 특화별 전투·지원 효과, 기존 작전과 증강, 저장 복원을 확인한다.
`sim/browser-specializations.cjs`는 데스크톱·모바일에서 34가지 선택과 잠금,
설명 창·도감·화면 폭을 확인한다. Playwright 경로는 기존 브라우저 검증처럼
`PLAYWRIGHT_MODULE`, 개발 서버 주소는 `FRONTIER_URL` 환경 변수로 지정한다.
