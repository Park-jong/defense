# 증강 모드 기획안

출격 화면에 **증강 모드**를 새 작전 모드로 추가한다. 10·20·30웨이브를 막아내면 증강 후보 3장 중 1장을 골라, 그 판이 끝날 때까지 규칙을 바꾸는 효과를 얻는다.
기존 5웨이브마다 나오는 보상 카드(`REWARDS`)와는 별개다. 아래 수치는 모두 초안이며 구현과 밸런스 확인을 거쳐 조정한다.

## 운영 방식

- **선택 시점**: 10·20·30웨이브 클리어 후, 3장 중 1장
- **등급**: 실버 → 골드 → 프리즘 순으로 강하다. 뒤 웨이브일수록 상위 등급 확률이 오른다(안).
- **리롤**: 판마다 1회(안)
- **노출 조건**: 종족 특화 증강은 현재 종족과 배치한 병력에 맞을 때만 등장시켜, 쓸 수 없는 카드를 줄인다.
- **UI**: 등급은 카드 테두리 색(은·금·무지개), 종류는 아이콘으로 구분하고 글자를 줄인다.

## 남은 결정

- 채택할 증강 번호와 첫 구현 범위
- **인플레이션**: "모든 비용"에 배치·강화·특화·재배치·벙커 보급까지 포함할지, 판매 환급도 2배 기준으로 계산할지
- **내 목숨을 아이어에**: 질럿 판매 시 환급률(일반 판매 기준인지 전액인지), 이후 질럿 재배치 허용 여부
- **야마토 프로토콜**: 일직선 판정의 길이와 폭(사거리 끝까지인지 맵 끝까지인지)
- **젤나가 맙소사**: 아몬의 능력치·패턴·처치 보상 설계, "5스테이지마다"를 증강 선택 이후 5웨이브 간격으로 셀지 5의 배수 웨이브로 셀지, 아몬을 놓치면 패배 처리할지
- 프리즘 등급이 강한 대가형 효과로 늘어난 만큼, 프리즘의 등장 확률(예: 30웨이브 전용)
- 등급별 등장 확률과 리롤 횟수
- 증강 모드에서 기존 5웨이브 보상 카드를 함께 줄지 여부
