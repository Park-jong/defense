# FRONTIER — 기지 방어

Phaser 3 + TypeScript + Vite로 만든 SF 타워 디펜스입니다.
테란·프로토스 병력 18종을 배치하고 강화해 군단의 50웨이브 진군을 막아 냅니다.

**플레이:** https://park-jong.github.io/defense/

## 특징

- **병력 18종**: 테란 9종, 프로토스 9종입니다.
  - 공격 병력과 지원 병력(사이언스 베슬·옵저버)이 있습니다.
  - 벙커는 마린·파이어뱃·고스트를 태우는 수송 건물입니다.
- **성장**: 병력마다 스킬 2종이 있고 Lv.5까지 강화합니다.
  - Lv.3부터 병력 전용 특화 두 갈래 중 하나를 고릅니다([docs/specializations.md](docs/specializations.md)).
- **적**: 저글링, 랩터, 바퀴, 여왕, 산란낭 변종, 디파일러 변종이 나옵니다.
  - 10웨이브마다 울트라리스크 보스가 고유 패턴을 들고 옵니다.
- **전장 3곳**: 프런티어, 협곡(고지대 사거리 +24), 두 입구가 만나는 합류 지대입니다.
- **난이도 3단계와 모드 5가지**: 방어 작전, 무한 방어, 벙커 부대, 제한 예산, 증강 작전입니다.
  - 증강 작전은 10·20·30웨이브마다 실버·골드·프리즘 증강 28종 가운데 하나를 고릅니다([docs/augments.md](docs/augments.md)).
- **지휘관 능력**: 궤도 폭격, 시간 교란, 보급 투하를 직접 씁니다.
- **기록**: 5웨이브마다 보상 선택, 자동 저장·이어하기가 있습니다.
  - 전투 통계(종합·보스·라인 피해), 업적과 외형 해금이 있습니다.
- **조작 환경**: PC와 모바일(가로 화면) 배치를 모두 지원합니다.

## 조작

| 키 | 동작 |
| --- | --- |
| `1`–`9` | 현재 진영의 병력 선택 |
| `T` / `R` | 테란 / 프로토스 진영 전환 |
| `Space` | 다음 웨이브 시작 |
| `A` | 자동 웨이브 켜기/끄기 |
| `U` / `S` | 선택한 병력 강화 / 판매 |
| `Z` / `X` | 선택한 병력의 스킬 장착 |
| `B` | 보급 상점 |
| `O` | 작전실(설정·통계·도감) |
| `P` | 일시정지 |
| `Enter` | 명령 입력 창 |
| `Esc` | 선택 취소 |

모바일에서는 화면의 아이콘 버튼으로 같은 기능을 씁니다.

## 실행

```bash
npm install
npm run dev       # 개발 서버 (http://localhost:5173)
npm run build     # 타입 검사 후 dist/ 빌드
npm run preview   # 빌드 결과 미리보기 (http://localhost:4173)
```

### URL 옵션

- `?test`: 마지막 50웨이브를 반복하는 테스트 전장을 엽니다.
  - 미네랄 제한이 없고, 저장·업적·보상은 기록되지 않습니다.
  - 출현 범위(기본·보스만·라인만)를 고를 수 있습니다.
  - 증강 작전에서는 원하는 증강을 바로 고를 수 있습니다.
- `?layout=mobile` / `?layout=desktop`: 화면 배치를 강제로 정합니다.

## 테스트

```bash
npm test                 # sim/*.test.cjs 전체 (node --test)
npm run test:campaign    # 캠페인·저장 규칙
npm run test:bunker      # 벙커 규칙
```

`sim/browser-*.cjs`는 브라우저 시나리오입니다.
실행하려면 외부에 설치한 Playwright 경로를 `PLAYWRIGHT_MODULE`로 지정하고, 개발 서버를 띄운 뒤 돌립니다.

## 구조

| 경로 | 내용 |
| --- | --- |
| `src/GameScene.ts` | 전투·배치·웨이브 진행의 중심 장면 |
| `src/data/` | 병력·적·스킬·전장·규칙 수치 |
| `src/campaign.ts` | 난이도·모드·보상·업적·저장 |
| `src/augments.ts` | 증강 정의와 효과 |
| `src/specializations.ts` | 병력 전용 특화 |
| `src/operations.ts` | 작전실 대화상자(설정·통계·도감) |
| `src/shop.ts` | 보급 상점(강화·특화·벙커 관리) |
| `src/themes.ts` | 화면 테마 |
| `sim/` | 단위 테스트와 브라우저 시나리오 |
| `docs/` | 증강·특화 설계 문서, 아트 프롬프트 |

## 배포

`main`에 푸시한 뒤 `npm run deploy`로 GitHub Pages(`gh-pages` 브랜치)에 배포합니다.
배포 전 훅이 푸시 여부를 확인하고 빌드합니다.
작업 규칙과 커밋 메시지 형식은 [AGENTS.md](AGENTS.md)를 따릅니다.
